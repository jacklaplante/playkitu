Open `samples/MinimalUnity` from the source repository in Unity 2022.3.62f3, then open `Assets/OfflineConsent.unity` and enter Play Mode. The explicit checkbox/button exercise the real host/controller with an issuer-disabled offline transport. This is an inert lifecycle demo, not a recording demo. No native runtime, network, Steam ticket, Editor-log upload or microphone is used. Production integration uses your own consent UI, `UnityRecordingFactory` and packaged native runtime.
