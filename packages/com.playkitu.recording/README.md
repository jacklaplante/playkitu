# playkitu Unity package

![playkitu](https://raw.githubusercontent.com/jacklaplante/playkitu/main/docs/assets/playkitu.png)

Consent-owned Windows x64 game-view/audio capture, optional commentary and bounded diagnostic upload.

The complete source repository includes native build tools, AWS Terraform/service code, the download tool and an independent Unity sample. Read its project README and docs/unity-integration.md.

Import does not start recording or initialize Steam. Your adapter supplies explicit consent, an existing ticket owner, trusted configuration and the packaged runtime path.

No prebuilt native binaries are included. Original package code is MIT licensed; restored dependencies and native components retain their own terms.
