# Security reports

Report vulnerabilities privately through this repository's **Security → Report a vulnerability** feature when enabled. If unavailable, contact the maintainer privately through their GitHub profile before disclosing exploit details.

Do not upload credentials, publisher keys, Steam tickets, bearer proofs, private recordings, raw logs or Terraform state. Use fabricated inputs in minimal reproductions.

This is experimental source. Local tests are scoped evidence, not a security audit or production certification. Dependency maintenance, TLS/codec requirements and native binary redistribution remain release work.
